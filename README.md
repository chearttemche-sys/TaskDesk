# TaskDesk

![Значок TaskDesk](docs/icon.png)

TaskDesk — портативный журнал задач для Windows. Записывайте работу в течение дня, а в конце недели, месяца или года собирайте отчёт по датам и приоритетам. Журнал хранится в обычном текстовом файле рядом с приложением.

## Быстрый старт

1. Скачайте [TaskDesk.exe](dist/TaskDesk.exe) кнопкой **Download raw file** на странице файла.
2. Положите его в папку, в которую можно записывать файлы, и запустите двойным щелчком. При первом запуске TaskDesk создаст пустой `tasks.txt`.
3. Введите название задачи, выберите приоритет и нажмите **Enter**. Галочка возле задачи запишет сегодняшнюю дату выполнения. Для работы, сделанной ранее, используйте **Записать выполненную** и выберите дату.

Для запуска нужны Windows и .NET Framework 4.x с WPF. Для переноса журнала на другой компьютер скопируйте `TaskDesk.exe` и свой `tasks.txt` в одну папку.

## Как собрать отчёт

На вкладке **Отчёт** выберите календарную неделю, месяц, год или свой диапазон. Неделя начинается в понедельник, обе даты входят в выборку. Выберите нужные приоритеты, при необходимости добавьте поиск по названию. Кнопка **Скопировать отчёт** скопирует отфильтрованные задачи с группировкой по дням или по важности.

## Формат журнала

Одна строка UTF-8 соответствует одной задаче. Пример с вымышленными записями:

```text
(A) Проверить восстановление тестового стенда
(B) Подготовить памятку для команды
x 2026-03-06 Обновить шаблон еженедельного отчёта pri:C
```

У открытой задачи приоритет стоит в начале строки. У завершённой сохраняются дата и приоритет на момент закрытия. Метка `inferred:1` обозначает оценку, присвоенную при переносе данных. Её можно подтвердить или исправить в карточке задачи.

При сохранении TaskDesk проверяет, менялся ли журнал на диске, и оставляет предыдущую версию в `tasks.txt.bak`.

## Клавиатура

- **Ctrl+N** — перейти к вводу новой задачи.
- **Enter** в поле новой задачи — добавить её.
- **Ctrl+F** на вкладке задач — перейти к поиску.
- **F5** — перечитать рабочий файл.

## Сборка

Исходный код написан на C# и WPF. На Windows выполните из корня проекта:

```powershell
.\build.ps1
```

Скрипт использует компилятор .NET Framework из Windows и создаёт `TaskDesk.exe` в корне проекта. Иконка включается в исполняемый файл.
